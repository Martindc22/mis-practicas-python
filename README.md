# Conversor de PDF a Excel (GUI)

Aplicación de escritorio desarrollada en Python con Tkinter y Pandas para automatizar la extracción y estructuración de datos desde archivos PDF hacia planillas de Excel (.xlsx).

## Funcionalidades
* **Interfaz Gráfica (GUI):** Selección sencilla de archivos mediante ventana de diálogo.
* **Extracción de Tablas:** Procesamiento e interpretación de datos desde documentos PDF.
* **Exportación Limpia:** Generación de archivos Excel ordenados y listos para análisis.

## Tecnologías Utilizadas
* Python 3
* Pandas
* Tkinter
